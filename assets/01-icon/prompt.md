# Icon Prompt
**Goal:** Create a minimalist, high-contrast graphical vector icon based on the successful "spine and ribs" visual style.

**Prompt:**
> "A minimalist, high-contrast graphical vector icon for an engineering software project. The design features a bold vertical axis (the 'spine') with clean, geometric segments or 'ribs' representing factory modules. A subtle, sleek gantry robot arm is integrated as a simplified element on the spine. Style: Tech-modern, engineering-grade, flat vector. Colors: Deep industrial blue (#003366) and a vibrant, professional green highlight (#00FF00). Solid white background. **ABSOLUTELY NO TEXT, NO LETTERS, AND NO ALPHABETIC CHARACTERS.** Focus entirely on the graphical symbol."
